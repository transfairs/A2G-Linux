Anstoss 2 Gold unter LinuxAnstoss 2 Gold on Linux

Der Fußballmanager von 1999 mit Lutris, Proton und Gamescope: Ein Skript installiert ihn von deiner CD oder dem GOG-Installer, und er sieht aus und verhält sich wie unter Windows. The 1999 football manager with Lutris, Proton and Gamescope: one script installs it from your CD or the GOG installer, and it looks and behaves as it does on Windows.

Unterstützte VersionenSupported versions

Jede Version bekommt einen eigenen Eintrag in Lutris, sie können also nebeneinander installiert sein. Each version gets its own entry in Lutris, so they can be installed side by side.

1999

Original-CDOriginal CD

Die CD (oder ein ISO davon) wird kopiert und danach als Laufwerk D: genutzt. Das Original-Setup läuft ohne Dialoge durch. The CD (or an ISO of it) is copied and used as drive D: from then on. The original setup runs without dialogs.

2007

DVD „ANSTOSS 2007“DVD "ANSTOSS 2007"

Die Kalypso-Neuauflage. Das Spiel wird von der DVD entpackt und aus seinem Kopierschutz-Mantel geholt, ohne etwas davon auszuführen. Die DVD wird nur bei der Installation gebraucht. The Kalypso re-release. The game is unpacked from the DVD and taken out of its copy protection shell without running any of it. The DVD is only needed during the installation.

GOG

Anstoss 2 Gold (GOG)

Der GOG-Installer wird mit innoextract entpackt. Kein CD-Laufwerk nötig, Banner und Cover kommen von GOG. The GOG installer is unpacked with innoextract. No CD drive needed, banner and cover come from GOG.

Das Repository enthält keine Dateien des Spiels, von Microsoft oder anderen Dritten. Du brauchst deine eigene CD, die DVD oder den GOG-Installer. The repository contains no files from the game, from Microsoft or other third parties. You need your own CD, the DVD or the GOG installer.

Was es machtWhat it does

Unter Wine zeigt das Spiel ohne Anpassungen schwarze Videos, abgeschnittene Texte und gespiegelte Wappen oder startet gar nicht. Ein kleiner Starter behebt das im Speicher. Die Spieldateien bleiben unverändert. Without adjustments, the game shows black videos, cut-off texts and mirrored crests under Wine, or doesn't start at all. A small launcher fixes this in memory. The game files stay unchanged.

16 Bit und 640×48016 bit and 640×480

Das Spiel läuft in einem 640×480-Wine-Desktop im Hicolor-Modus. Gamescope skaliert ihn scharf in ein frei veränderbares Fenster, auf Wunsch auch im Vollbild. The game runs in a 640×480 Wine desktop in hicolor mode. Gamescope scales it sharply into a freely resizable window, or fullscreen if you like.

VideosVideos

Intro, Outro, EM, WM und Finale werden aus Indeo 3 umgewandelt. Auch das „Tor des Monats“ und die Pokalauslosung mit den Vereinsnamen auf dem Schild funktionieren. Intro, outro, European Championship, World Cup and final are converted from Indeo 3. "Goal of the month" and the cup draw with the club names on the sign work as well.

Schriften wie unter WindowsFonts as on Windows

Überschriften, Tabellen und Statistiken werden nicht mehr abgeschnitten. Vereinsnamen in großer Schrift bekommen eine eigens gebaute breite Schrift. Headings, tables and statistics no longer get cut off. Club names in the large font get a specially built wide font.

Wappen, Flaggen, MaskottchenCrests, flags, mascot

Keine riesige Flagge mehr kopfüber oben links, und das Maskottchen in den Dialogen wird nicht mehr abgeschnitten. No more huge upside-down flag in the top left, and the mascot in the dialogs no longer gets clipped.

Fenster und MausWindow and mouse

Titelleisten wie unter Windows, eigener Name und Icon im Dock, und die Maus reagiert auch nach dem Verkleinern oder Vergrößern des Fensters weiter. Title bars as on Windows, its own name and icon in the dock, and the mouse keeps working after resizing the window.

Ton und TorlimitsSound and goal limits

Der Ton kommt aus dem Standardgerät des Systems. Optional lässt sich die Torbegrenzung der Spiel-Engine aufheben. Beide Patches stammen aus A2G-Patcher und lassen sich zurücknehmen. Sound comes from the system's default device. Optionally, the goal limit of the match engine can be lifted. Both patches come from A2G-Patcher and can be taken back.

Editor und A2G-TrainerEditor and A2G-Trainer

Beide bekommen einen Eintrag im Anwendungsmenü und laufen mit demselben Proton wie das Spiel, auch während es läuft. Both get an entry in the application menu and run with the same Proton as the game, even while it is running.

Datensatz und SpielständeData set and save games

Bei der Installation kannst du einen Datensatz und deine Spielstände aus einer Zip-Datei oder einem Ordner übernehmen. During the installation you can import a data set and your save games from a zip file or a folder.

Installation

Getestet mit Lutris als Paket der Distribution (nicht Flatpak) und GE-Proton11-12. Tested with Lutris as a regular distribution package (not the Flatpak) and GE-Proton11-12.

  1. VoraussetzungenRequirements

    • Lutris aus der PaketverwaltungLutris from your package manager
    • GE-Proton11-12 in ~/.local/share/Steam/compatibilitytools.d/GE-Proton11-12 in ~/.local/share/Steam/compatibilitytools.d/
    • ffmpeg, gamescope, imagemagick, python3, zenity, glib-compile-schemas, gcc
    • Für GOG und die DVD 2007: innoextractFor GOG and the 2007 DVD: innoextract
    • Optional: die Microsoft-Core-Fonts deiner Distribution, für Impact in den ÜberschriftenOptional: the Microsoft core fonts of your distribution, for Impact in headings

  2. Repository holenGet the repository

    $ git clone https://github.com/transfairs/A2G-Linux.git ~/a2g-linux
$ cd ~/a2g-linux

  3. Installer startenRun the installer

    CD einlegen oder ISO einhängen (Doppelklick im Dateimanager oder udisksctl loop-setup -f anstoss2.iso). Insert the CD or mount the ISO (double-click in the file manager or udisksctl loop-setup -f anstoss2.iso). 

    $ ./install.sh --cd /run/media/$USER/<CD-Label>

    Die DVD wird an der Datei ANSTOSS_2_GOLD/Setup.exe erkannt. The DVD is recognized by the file ANSTOSS_2_GOLD/Setup.exe. 

    $ ./install.sh --cd "/run/media/$USER/ANSTOSS 2007"

    Mit dem deutschen GOG-Installer (1.0 fix2): With the German GOG installer (1.0 fix2): 

    $ ./install.sh --gog ~/Downloads/setup_anstoss_2_gold_der_fuballmanager_1.0_fix2_\(german\)_\(48434\).exe

  4. In Lutris bestätigenConfirm in Lutris

    Lutris öffnet sich mit dem Installer. Danach fragt es optional nach Datensatz, Spielständen, Torlimits und A2G-Trainer. Außer dem Trainer und den GOG-Bildern wird nichts heruntergeladen. Lutris opens with the installer. Afterwards it optionally asks for a data set, save games, goal limits and A2G-Trainer. Apart from the trainer and GOG's images, nothing is downloaded.

Fenster und Skalierung: Rechtsklick auf das Spiel, „Konfigurieren“, „Systemoptionen“. Dort lassen sich Fenster- oder Vollbildmodus, Startgröße und der Gamescope-Filter (scharf, weich, ganzzahlig) einstellen. Window and scaling: right-click the game, "Configure", "System options". There you can set windowed or fullscreen mode, initial size and the Gamescope filter (sharp, smooth, integer).

Häufige ProblemeCommon problems

Mehr dazu in der ausführlichen Anleitung. More in the full guide.

Nur schwarzer Bildschirm (GNOME 50 / Ubuntu 26.04)Black screen only (GNOME 50 / Ubuntu 26.04)

Gamescope stürzt beim Start ab. Die Umgebungsvariable GSETTINGS_SCHEMA_DIR muss auf den Ordner gschemas im Prefix zeigen. Neu erzeugen mit ./install.sh --make-schemas ~/Games/anstoss-2-gold/gschemas. Gamescope crashes at startup. The environment variable GSETTINGS_SCHEMA_DIR must point to the gschemas folder in the prefix. Recreate it with ./install.sh --make-schemas ~/Games/anstoss-2-gold/gschemas.

Mausklicks kommen nach dem Verändern der Fenstergröße nicht mehr anMouse clicks stop arriving after resizing the window

LD_PRELOAD muss in den Umgebungsvariablen auf gsfix.so im Prefix-Ordner zeigen (voller Pfad). LD_PRELOAD in the environment variables must point to gsfix.so in the prefix folder (full path).

„Windows muß sich im Hicolormodus befinden“

Das Spiel wurde nicht über a2start.exe im 640×480-Wine-Desktop gestartet. Ausführbare Datei und Argumente unter „Spieloptionen“ prüfen. The game was not started through a2start.exe in the 640×480 Wine desktop. Check the executable and arguments under "Game options".

„kein Intel Indeo 3.2-Videodekompressor“

Auch hier lief das Spiel nicht über a2start.exe, oder es ist eine andere Programmversion. a2start.log im Spielordner zeigt, welche Anpassungen angewendet wurden. Here too, the game did not run through a2start.exe, or it is a different program version. a2start.log in the game folder shows which changes were applied.
